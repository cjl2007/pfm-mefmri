# Local release draft · 2026-09-21

This is a local preparation checkpoint for maintainer review. It is not a
published GitHub release, tag, or claim of clinical clearance.

## Included

- Individual-focused README and gallery covering coregistration, fieldmap/SDC
  review, motion grayplots, NSI, seed FC, Infomap, RidgePFM, continuous
  network representations, and the optional TANS workflow.
- Guides for longitudinal study organization and explicit TANS input/configuration.
- Current first-party runner, module, and helper code brought into the release,
  including the missing QC entrypoints and the TANS module.
- Portable release configuration and explicit TANS shell/YAML examples. TANS
  stays disabled by default; hardware choices come from the study configuration.
- The existing no-fieldmap metadata regression test is retained alongside the
  PFM and TANS tests. Bundled HCP/NSI dependencies and release citation metadata
  are preserved, not refreshed from the network.

The local development checkout retains its existing site/study configuration;
the release gets a portable main template. Private study-specific configs,
participant derivatives, FreeSurfer license files, and development workspaces
are not copied into the release.

## Companion TANS checkpoint

Use the pfm-tans `2026.09.21` local snapshot with this draft. The TANS repository
remains separate. Its snapshot manifest records file fingerprints so the exact
code and reviewed gallery can be recovered without a Git commit or tag.

## Checks before publication

1. Review the complete diff, including untracked implementation files. Do not
   accidentally publish only the README or stage the parent development tree's
   embedded release checkout as if it were source code.
2. Review licenses and redistribution permissions for both projects, dependencies,
   priors, calibration resources, and figures. No new license is inferred here.
   Existing release citation metadata lists MIT and version 0.1.0; confirm the
   intended license text and update the formal citation/version metadata when
   choosing a public release. That prior metadata is preserved by this draft.
3. Review the replacement multi-visit gallery added on 2026-10-13: QC across
   13 sessions/26 runs, a single-run grayplot, saved seed-FC movie, and pooled
   individual-network maps. Captions, fingerprints, and private provenance were
   updated together; the separate TANS illustrations were retained.
   Approve sharing of every participant-derived image.
   Display-name cleanup does not guarantee anonymization; cropped brain images
   and individual network maps remain participant-derived. Private input paths
   stay in local provenance.
4. Review and run the documented tests in the intended runtime environment.
   Synthetic/stub checks do not replace a representative full pipeline run.
5. Complete installation paths and optional resources for the study. In
   particular, homogeneity spin-null diagnostics need a suitable rotation-index
   CIFTI not bundled here; that optional check is off in the portable template.
   Optional NORDIC and spatial-classifier resources require separate installation
   and permission review; they are not newly vendored by this draft.
6. Review the paired repositories and choose the exact commit/tag/version scope.
   Commit, tag, remote creation, release publication, and push still require
   explicit approval. No such operation is performed by this draft.

The gallery distinguishes unchanged production reportlets from native Workbench
documentation renderings and curated TANS layouts. Figure examples are not a
promise that every optional output is generated by every configuration.
