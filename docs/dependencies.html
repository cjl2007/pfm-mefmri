Dependencies and installation

Start with a Linux environment and the configuration guide. The repository includes pipeline scripts, an HCP Pipelines snapshot, templates, and a pinned pfm-nsi Git submodule. It does not install FSL, FreeSurfer, Workbench, SimNIBS, Conda, or your Python environments.

The software inventory records the development stack and module-level commands. These are reference versions, not a guarantee that every version combination or optional branch has been validated.

Initialize the NSI dependency with git submodule update --init --recursive. The wrapper uses lib/pfm-nsi; its Python dependencies still need installation.

Python and multi-echo processing

Use a dedicated Python environment with numpy, scipy, nibabel, pandas, matplotlib, and scikit-learn. Set PIPELINE_PYTHON to its interpreter. imageio is needed for optional GIF outputs and openpyxl for Excel correction tables. Pillow is used by the optional release-documentation checker.

Multi-echo processing also needs tedana, including the tedana, t2smap, and ica_reclassify commands. The recorded pipeline stack uses Python 3.10 and tedana 26.0.0. For example:

conda create -n mefmri_env python=3.10 pip
conda run -n mefmri_env python -m pip install \
  'tedana==26.0.0' numpy scipy nibabel pandas matplotlib scikit-learn imageio openpyxl
conda run -n mefmri_env tedana --help
conda run -n mefmri_env ica_reclassify --help

This is an environment starting point, not a fully pinned reproduction of all recorded dependencies. Follow upstream installation instructions when adapting versions for your platform. The config's example Conda environment names must match environments you actually create.

MATLAB is not required for the Python PFM/TANS workflow. It is required if you choose the optional NORDIC import branch. Container recipes are development starting points and do not imply that every optional dependency is installed.

Check your environment

After configuring/loading your site environment, use the command checks in the software inventory. At minimum, verify the selected branches' executables and your Python imports:

command -v fslmaths recon-all wb_command parallel charm
/path/to/your/python/environment/bin/python -c \
  'import numpy, scipy, nibabel, pandas, matplotlib, sklearn'

Also check tedana, warpkit, or AROMA within their own configured environments. Then run one subject through validation before starting the full pipeline. No package installer in this guide launches participant processing.

RidgePFM CV reports

CV uses NumPy, SciPy, and NiBabel. Workbench and Pillow are required for flat/inflated report captures when PFM_RF_CV_RENDER=1. Pillow builds without WebP support use PNG. An available g++ compiler with OpenMP accelerates local FC calculations; a Python fallback is provided.
