RidgePFM parameter trade-offs

Maps should be reproducible while retaining reliable individual-specific FC information—the goal of PFM.

Moving right means more reproducible network labels; moving up means recovering more individual atlas departures that repeat independently, with the same alternative network identity. Label agreement uses a held-out map with matched parameters; departure recovery uses a shared, independent Pearson reference.

Each curve fixes λ; numbers beside points are spatial-prior weights. Stronger priors generally improve agreement while suppressing individual variation. Shaded boxes highlight reasonable trade-off regions. In dense data, λ = 3–30 with spatial weight 0–0.025 offers a useful range to explore.

What the parameters change

λ regularizes competition among FC templates; spatial weight controls the influence of the population prior. Because FC coefficients are standardized, higher λ can preserve more individual information rather than simply suppressing FC. Very large λ approaches direct template matching; λ = 0 is multitemplate OLS.
