Local release draft · 2026-09-21

This is a local preparation checkpoint for maintainer review. It is not a published GitHub release, tag, or claim of clinical clearance.

Included

  • Individual-focused README and gallery covering coregistration, fieldmap/SDC review, motion grayplots, NSI, seed FC, Infomap, RidgePFM, continuous network representations, and the optional TANS workflow.
  • Guides for longitudinal study organization and explicit TANS input/configuration.
  • Current first-party runner, module, and helper code brought into the release, including the missing QC entrypoints and the TANS module.
  • Portable release configuration and explicit TANS shell/YAML examples. TANS stays disabled by default; hardware choices come from the study configuration.
  • The existing no-fieldmap metadata regression test is retained alongside the PFM and TANS tests. Bundled HCP/NSI dependencies and release citation metadata are preserved, not refreshed from the network.

The local development checkout retains its existing site/study configuration; the release gets a portable main template. Private study-specific configs, participant derivatives, FreeSurfer license files, and development workspaces are not copied into the release.

Companion TANS checkpoint

Use the pfm-tans 2026.09.21 local snapshot with this draft. The TANS repository remains separate. Its snapshot manifest records file fingerprints so the exact code and reviewed gallery can be recovered without a Git commit or tag.
