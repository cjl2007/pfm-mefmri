Methods and data

Held-out FC profile homogeneity is calculated in test data using network labels fitted in training data. It is the vertex-count-weighted mean correlation between spatially standardized whole-brain FC profiles within each network. The displayed score subtracts the mean for rotated copies of the training map on the cortical sphere (the spatial null). It measures how well the fitted network organization generalizes to held-out data. Undefined rotations are omitted within each comparison. Network map reliability is measured with mean network Dice. Selection maximizes Dice within the allowed homogeneity loss. The FC / Dice average rescales both metrics within the grid and is for display only.

Scores average the independent A/B comparisons. A/B map previews use the first comparison; the saved map is refit on all data. CV selection scores are not an independent test of the final map.
