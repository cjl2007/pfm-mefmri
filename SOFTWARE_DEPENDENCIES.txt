ME-fMRI Pipeline Software Dependencies
=====================================

Getting started
---------------

Start with docs/dependencies.md for installation links and core versus optional
requirements, then docs/configuration.md for study-owned config setup. Clone with
--recurse-submodules (or run git submodule update --init --recursive) for pfm-nsi.
Example environment names are configurable, not environments installed by this repo.

Overview
--------

This document lists the software versions used by the current pipeline release.
Where an exact version is available from the repository, configured runtime
environment, or container definition, it is listed below.
These are recorded development-stack references, not a fresh end-to-end test of
every optional branch in the release draft. Container launchers and image recipes
are included as development tooling; no complete image build is validated here.

E. MEDIC / warpkit environment
- Conda environment name: `warpkit_env`
- Python: `>=3.11`
- Required package/commands when `DISTORTION_CORRECTION_MODE="medic"` and
  per-echo phase companions are available:
  - `warpkit`
  - `wk-medic`
  - `wk-apply-warp`
  - `wk-convert-warp`
  - `wk-convert-fieldmap`
  - `wk-compute-jacobian`

Default warpkit-related config:
- The template selects `DISTORTION_CORRECTION_MODE="medic"`; review this for your acquisition.
- MEDIC is supported when per-echo phase images are present. If MEDIC is
  requested but phase companions are absent, the runner falls back to TOPUP
  when AP/PA field maps are available.
- `WARPKIT_ENV="warpkit_env"`
- `WARPKIT_ACTIVATE_MODE="conda_activate"`
- `SBREF_ECHO_COMBINATION="mean"` and `SBREF_MAX_TE_MS=60` mirror the
  standard coregistration SBRef echo-combination policy for all distortion modes.
  Optional SBRef modes `t2s` and `paid` call `t2smap` from `TEDANA_ENV`; `sos`
  uses only FSL.

Recommended environment model:
- Keep `warpkit_env` separate from `mefmri_env`. The tested tedana stack uses
  Python 3.10, while current warpkit requires Python >=3.11.

Suggested setup/verification:
```bash
conda create -n warpkit_env python=3.11 pip -y
conda run -n warpkit_env python -m pip install warpkit
"$(conda info --base)"/envs/warpkit_env/bin/wk-medic --help
"$(conda info --base)"/envs/warpkit_env/bin/wk-compute-jacobian --help
```

The pipeline should resolve `wk-*` binaries from the configured environment
path when `WARPKIT_ACTIVATE_MODE` is `conda_activate` or `conda_run`, mirroring
the tedana resolver and avoiding stale user-local command shims.

5) Optional / Conditional Dependencies
--------------------------------------

A. ANTs
Only needed if:
- `APPLY_N4_BIAS=1`

Required command:
- `N4BiasFieldCorrection`

B. PFM-NSI CLI
Needed for the default NSI module path:
- `NSI_USE_EXTERNAL_CLI=1`

Config requirement:
- set `NSI_EXTERNAL_ROOT` to the local NSI repository path
- bundled default location: `lib/pfm-nsi`

Bundled version reference:
- `pfm-nsi==0.1.0`

C. Infomap
Only needed if:
- `PFM_STRATEGY=infomap`

Required command:
- `infomap`

If `infomap` is not on `PATH`, set:
- `PFM_INFOMAP_BINARY=/full/path/to/infomap`


6) Manual Checks
----------------

Core command presence check:

for c in \
  bash awk sed \
  fslmaths fslmerge flirt topup mcflirt fslnvols fslsplit fslroi fslval \
  convert_xfm convertwarp applywarp invwarp slicetimer bet \
  mri_binarize mri_convert mri_surf2surf bbregister tkregister2 \
  wb_command parallel python3 tedana ica_reclassify ffmpeg ffprobe; do
  command -v "$c" >/dev/null 2>&1 || echo "MISSING: $c"
done

Tedana environment check:

conda run -n mefmri_env python -c "import sys, tedana, numpy, nibabel, pandas, scipy, matplotlib, sklearn, imageio, openpyxl; \
print('python==' + sys.version.split()[0]); \
print('tedana==' + tedana.__version__); \
