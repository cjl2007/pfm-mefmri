# Infomap Review Scene Template

`Bipartite_PhysicalCommunities+AlgorithmicLabeling_ManualReview.template.scene`
is a reusable Connectome Workbench scene template for per-density Infomap manual
review.

The template was derived from the HC05 manual-labeling scene and made
subject-neutral with placeholders:

- `__SCENE_NAME__`
- `__SUBJECT__`

During Infomap network labeling, `lib/pfm_infomap_labeler.py` rewrites the
template into each graph-density folder as:

```text
Bipartite_PhysicalCommunities+AlgorithmicLabeling_ManualReview.scene
```

The scene expects the per-density review files generated by the labeler:

- `Bipartite_PhysicalCommunities+AlgorithmicLabeling.dlabel.nii`
- `Bipartite_PhysicalCommunities+AlgorithmicLabeling_InfoMapCommunities.dlabel.nii`
- `Bipartite_PhysicalCommunities+AlgorithmicLabeling_FC_WholeBrain.dtseries.nii`
- `Bipartite_PhysicalCommunities+AlgorithmicLabeling_FC_btwn_InfoMapCommunities.dtseries.nii`
